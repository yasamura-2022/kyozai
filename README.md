# 小学校の授業で使う教材（HTML）

小学校の授業で、子どもが直接使うための教材です。
すべて **1つの `.html` ファイルで完結**しています。

## 使い方

**ファイルをダブルクリックするだけです。** インストールも設定も要りません。

- インターネットにつながっていなくても動きます
- 書体も中に入っているので、どの端末でも同じ見た目になります
- iPad でも動きます

## 中身

### 漢字のれんしゅう（一人ずつ使う）

| ファイル | 対象 |
|---|---|
| `kanji_1nen.html` | 1年生 |
| `2年生のかんじ_れんしゅう.html` | 2年生（160字） |
| `kanji_3nen_v2_fixed.html` | 3年生 |
| `kanji_4nen.html` | 4年生 |

指で書いて練習します。筆順が出ます。「ごうかく」にした漢字は記録されるので、
次に開いたとき続きからできます。

### 算数（一人ずつ使う）

単位のかんさんは、量ごとに別ファイルにしています。1つのアプリに3つの量を入れると、
子どもが今やっていない量のほうを触り始めてしまうためです。3つとも操作と見た目は同じで、
ステップ1「きまり はっけん」→ ステップ2「ドリル」→ ステップ3「ふたつの たんい」
→ ステップ4「たす・ひく」の順に進みます。

| ファイル | 内容 |
|---|---|
| `くりあがりくりさがり_れんしゅう.html` | くり上がり・くり下がりのある計算 |
| `ながさのかんさん_れんしゅう.html` | 長さのかんさん（mm・cm・m・km）。画面には「長さ」と出ます |
| `おもさのかんさん_れんしゅう.html` | 重さのかんさん（g・kg・t）。画面には「重さ」と出ます |
| `かさのかんさん_れんしゅう.html` | かさのかんさん（L⇄dL・L⇄mL） |
| `あまりのあるわり算.html` | あまりのあるわり算。1こずつ分けていく動きを見せる「わけて みる」、わられる数を1ずつ増やしてあまりの変わり方を並べる「くらべて みる」、自分で解く「やって みよう」の3画面 |
| `なんばい_れんしゅう.html` | 何倍・関係図。テープ図で倍を見せ、関係図の□をうめ、文章題で「もとにする数」を決めるところまで |
| `かけ算のひっさん_れんしゅう.html` | 1けたをかけるかけ算の筆算。えんぴつを10のたばとばらに分けて、十の位の分と一の位の分を合わせると答えになることを見せます |
| `2けたをかけるひっさん_れんしゅう.html` | 2けたをかけるかけ算の筆算。2だんめを十の位から書くところを、札を置く操作で扱います。くり上がりのメモらんつき |
| `分数_れんしゅう.html` | 分数の意味と表し方。1mのテープを等分して 1/n の何こ分かを見せ、数直線まで進みます |
| `三角形_れんしゅう.html` | 二等辺三角形と正三角形。辺の長さで仲間分けし、おって重なる角を見つけ、角を大きい順に並べ、しきつめます |

### 音楽（一人ずつ使う）

| ファイル | 内容 |
|---|---|
| `リコーダーのゆびづかい.html` | ソプラノリコーダーの運指（**ジャーマン式**）。音名を見て指の形が瞬時に出てこない子のための練習です |

3つのステップがあります。「ゆびを 見る」で音を選んで指の形を確かめ、「ゆびを おさえる」で
音名から自分で穴をふさぎ、「ながして ふく」でフレーズがテンポに合わせて流れてきます。
低いド・レから高いレまで、どのステップでも同じ9音を扱います。

リコーダーの絵は **うたくちが下、あさがおが上** です。iPad を机に置いて上からのぞくと、
持っているリコーダーは「口もとが手前・先が奥」に見えるので、それにそろえてあります。
左手が下（口に近いほう）、右手が上になります。

「ゆびを おさえる」では、答え合わせのあとに **「♪ いっしょに ふく」** が出ます。
2秒鳴って1.4秒休むのを4回くり返し、鳴っているあいだはバーがたまって「ふーっ」、
休みは「いきを すって」と出ます。指の形は画面に出たままなので、それを見ながら吹けます。

「ながして ふく」は **2つの音だけ** から始まる4段階です（2つの音 → 3つ → 4つ → ぜんぶ）。
指の出し入れが1か所だけのところから始めて、少しずつ増やします。段階も練習も、
はじめから全部えらべます。

指の名前は文字ではなく **手の絵** で出します。押さえる指は色がついてリコーダーに触れ、
はなす指は白くて浮いています。自分の手をその形にすればよいので、読まなくても分かります。

どのステップでも、**前の音からどの指が変わるか**を出します（「ソ → ラ　ひだりの くすりゆびを
はなす」）。指使いでつまずくのは、音そのものではなく音と音のつなぎ目だからです。

流す画面に出す指の図は「いま」の1つだけです（吹きながら次の図まで見る余裕はありません）。
次に来る音は、上を流れてくる音名で分かります。テンポは ♩=50〜120 で変えられます。
メロディは端末の中で作っているので音源ファイルは要りませんが、**教室で一斉に使うときは「音 なし」に
できます**。曲は教科書の曲ではなく、ソラシ・ミファソの行き来から音階まで、練習用の10本です。

## 子どもに配るとき

Google サイトのページに埋め込んで、子どもにはそのページを開かせています。

1. Google サイトで「挿入 → 埋め込む → 埋め込みコード」を選ぶ
2. `.html` ファイルをテキストエディタで開き、**全文をコピーして貼り付ける**
3. 挿入して公開

ファイルをそのまま配るより、この方法が確実です。
（ロイロノートの資料箱に置くこともできますが、HTMLはカードとして使えないため、
子どもがダウンロードして別アプリで開く操作が必要になり、低学年には向きません）

## つくりかたの方針

- **1ファイル完結**。ダブルクリックで開いて動くこと
- **外部読み込みなし**。学校のネットワークは制限が強く、家庭でも開くため
- **操作の文字はひらがな**。「つぎへ」「できた！」「けす」
- 目が疲れないよう、淡い紙の色を基調にしています
